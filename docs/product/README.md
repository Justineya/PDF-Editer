# ForgePDF 产品设计（从 0 到 1）

本地优先、性能优先的全能 PDF 工作台。终局对标 Acrobat Pro 能力集；交付上分阶段，每一阶段都可日用。

## 当前实现状态（2026-09）

可运行应用在 `apps/web`：**Phase 1–4 功能已在本地 Web 工作台落地**（阅读批注整理、轻编辑表单签名、OCR/转换、密文/安全/比较/本地 AI）。启动见根目录 README。

## 已知体验缺口（2026-09，冒烟实测）

- **选择（已实现）**：Text Layer 拖选 + 浮动条（复制/高亮/下划线/删除线/覆盖替换）。验收脚本：`scripts/smoke-select-edit.mjs`。
- **编辑图标与 WPS 框选流（已实现）**：编辑工具条 SVG 图标；框选 → 区域菜单（添加文字 / 修改原文 / 覆盖改字 / 白盖 / 插图）→ 行内输入。
- **仍缺 / 弱**：选择浮动条仍是文字按钮（无图标）；「修改原文」对 CJK/CID 不稳；桌面壳 GUI 冒烟未在无显示器环境跑通；文档矩阵部分条目仍滞后于代码。
- 细节 backlog 见 [07](./07-selection-editing.md)。

```
P0 骨架 → P1 读/批/整理 → P2 轻编辑/表单/签名 → P3 OCR/转换 → P4 密文/安全/比较/本地 AI
```
