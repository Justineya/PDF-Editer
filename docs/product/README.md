## 推荐路径（已拍板）

**桌面主产品（Tauri 2 + PDFium）**，本地文件默认不出机；浏览器仅作远期可选壳。  
先做 Phase 0–1（快读 + 批注 + 页面整理），再向真编辑 / OCR / 转换 / 红act 演进。

## 阶段速览

```
P0 骨架与性能 → P1 读/批/整理 → P2 轻编辑/表单/签名
    → P3 真编辑/OCR/转换 → P4 合规/印刷/可选 AI
```
