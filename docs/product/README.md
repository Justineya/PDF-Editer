# ForgePDF 产品设计（从 0 到 1）

本地优先、性能优先的全能 PDF 工作台。终局对标 Acrobat Pro 能力集；交付上分阶段，每一阶段都可日用。

## 当前实现状态（2026-09）

可运行应用在 `apps/web`：**Phase 1–4 功能已在本地 Web 工作台落地**（阅读批注整理、轻编辑表单签名、OCR/转换、密文/安全/比较/本地 AI）。启动见根目录 README。

## 已知体验缺口（2026-09）

- **选择**：仍是框选高亮，不是字形级选字；见 [07](./07-selection-editing.md) 包 A。
- **编辑**：仍是点击盖字，缺少对象选中/拖拽/白盖替换；见 07 包 C/D。

## 阶段速览

```
P0 骨架 → P1 读/批/整理 → P2 轻编辑/表单/签名 → P3 OCR/转换 → P4 密文/安全/比较/本地 AI
```
