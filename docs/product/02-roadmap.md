# 分阶段路线图

终局：**全能本地 PDF 工作台**。交付原则是「每一阶段都是可日用的完整产品」，下一阶段只增加能力域，不推翻上一代交互骨架。

```
Phase 0  骨架与性能地基
   ↓
Phase 1  日用阅读 + 批注 + 页面整理     ← 第一个「自己天天用」里程碑
   ↓
Phase 2  轻编辑 + 表单填写 + 签名
   ↓
Phase 3  真编辑 + OCR + 转换
   ↓
Phase 4  安全合规 + 印刷/无障碍 + 可选 AI/协作
```

---

## Phase 0 — 骨架与性能地基

**目标**：证明「大文件也快」；定死进程模型、渲染管线、文档会话模型。

### 必须交付

| ID | 项 | 验收 |
|----|----|------|
| P0-1 | Tauri 2 桌面壳 + 多标签窗口框架 | 开/关文档、多标签切换 |
| P0-2 | PDFium 渲染管线（原生绑定） | 连续翻页、缩放、旋转预览 |
| P0-3 | 异步解码 + 图块/页级缓存 | 前后翻页无长时间白屏 |
| P0-4 | 文档模型：`DocumentSession`（路径、页数、元数据、脏标记） | 可单元测试 |
| P0-5 | 性能探针面板（dev） | 显示 open latency、fps、缓存命中 |
| P0-6 | 许可与依赖清单自动化 | CI 输出 NOTICE |

### 本阶段不做

批注持久化、编辑、OCR、转换、任何网络功能。

### 退出标准

- 200 页样例集达到愿景里的打开/流畅指标
- 崩溃：连续翻完全书 0 crash

## Phase 1 — 日用阅读 + 批注 + 页面整理

**目标**：替代日常「阅读器 + 简单整理工具」；成为默认打开 PDF 的应用。

### 查看与导航

- 单页 / 双页 / 连续滚动
- 缩略图、大纲（bookmarks）、页码跳转
- 全文搜索（文本层；高亮当前命中）
- 适合夜间的主题（跟随系统，避免纯炫技暗色）

### 批注（Annotation）

| 类型 | 说明 |
|------|------|
| 高亮 / 下划线 / 删除线 | 基于文本选取 |
| 便签 / 文本框 | 页面浮动 |
| 墨迹 / 形状 | 笔压可选（有数位板则用） |
| 图章 | 内置少量 + 自定义图片 |

持久化：写入 PDF Annotation 字典（标准可互操作），另可选侧车 `.forge-annot.json` 做备份/迁移。

### 页面组织（Organize）

合并、拆分、提取、删除、旋转、重排、插入空白页、导出选中页。

### 导出

另存为、扁平化批注（可选）、打印。

### 退出标准

- 自己连续 2 周以本应用为默认 PDF 阅读/批注工具
- 整理类任务不再需要 Stirling/PDFsam

---

## Phase 2 — 轻编辑 + 表单 + 签名

**目标**：覆盖「改几个字、填表、签字」的高频生产任务。

### 轻编辑（Overlay / Content patch）

- 叠加文本、图片、水印、页眉页脚、页码
- 覆盖矩形（视觉遮盖，**不是**合规红act）
- 删除/替换指定内容流对象（有限，明确标注能力边界）

### 表单

- 填写现有 AcroForm
- 导出填好的 PDF
- （可选）简单创建文本/勾选域

### 签名

- 手绘签名、图片签名、文字签名
- 放置到签名域或任意位置
- 基础密码加密 / 权限（打印/复制限制）

### 退出标准

- 合同类：打开 → 填 → 签 → 回传，全在本应用完成
- 明确 UI 标注：本阶段「遮盖 ≠ 红act」

---

## Phase 3 — 真编辑 + OCR + 转换

**目标**：进入专业编辑器档位；能力开始逼近 Acrobat Standard/Pro 的日常子集。

### 真编辑（Hard）

- 文本框识别与内容流级编辑（字体匹配、字号、颜色）
- 段落级有限回流（先单栏/简单版式，复杂版式降级为框编辑）
- 图像：移动/缩放/替换/导出
- 撤销重做栈与编辑事务

### OCR

- 本地 OCR 引擎（如 Tesseract 或更高质量引擎，可替换）
- 输出：可检索文本层；可选「OCR 后可编辑」
- 中文优化与版面分析（分阶段提升）

### 转换

| 方向 | 策略 |
|------|------|
| PDF → 图 | 自研/PDFium 渲染导出（先做） |
| 图 → PDF | 自研 |
| PDF ↔ Office | 先接 LibreOffice/成熟引擎作后端；自研版面重建并行研究 |
| PDF → 纯文本/Markdown | 自研提取 |

转换质量分两档：**快速** / **尽量保真**，避免单一「魔法按钮」期望失控。

### 退出标准

- 中等复杂度中文文档可完成「改标题、换图、OCR 扫描件检索」
- Office 转换有可复现的质量样例集与回归

---

## Phase 4 — 合规、印刷、智能与扩展

**目标**：补齐 Acrobat Pro 差异化专业能力；成为「个人全能」终局。

### 安全与合规

- **真红act**（删除内容流、图像区域、元数据、隐藏文本）
- 证书签名、时间戳（按地区法规扩展）
- 元数据查看/清理、PDF 优化线性化
- 文档比较（页面渲染差分 → 文本级对比）

### 印刷与无障碍

- PDF/A 导出、基础 Preflight
- 无障碍标签检查与简单修复

### 智能（可选模块）

- 本地或自选 API：摘要、问答、带页码引用
- 不绑定单一厂商；默认可关

### 协作（可选）

- 导出批注 XFDF / 标准批注
- 局域网只读共享或自托管（非必须）

### 退出标准

- 功能矩阵对标 Acrobat Pro「个人专业使用」条目 ≥ 90% 覆盖
- 红act 有对抗测试用例（拷贝/提取不到敏感文本）

---

## 阶段优先级总览

| Phase | 主题 | 对标档位 | 自己用价值 |
|-------|------|----------|------------|
| 0 | 性能地基 | — | 决定产品能否成立 |
| 1 | 读 + 批 + 整理 | Reader+ 工具箱 | ★★★★★ |
| 2 | 填 + 签 + 轻改 | Standard 入门 | ★★★★★ |
| 3 | 真编辑 + OCR + 转换 | Standard → Pro | ★★★★ |
| 4 | 红act / 印刷 / AI | Pro | ★★★（按需） |

## 刻意延后但预留扩展点

- 插件 API（转换引擎、OCR、AI、存储）
- 脚本/Action 批处理（对标 Action Wizard）
- 移动端（同一文档模型，异壳）

详见 [功能矩阵](./03-feature-matrix.md)。
