# 信息架构与交互设计

## 1. 主界面结构（单一工作区）

```
┌──────────────────────────────────────────────────────────────────────────┐
│  菜单/应用名    文件名 ▾ 脏标记          [搜索]  [命令面板]  窗口控件     │
├────────┬───────────────────────────────────────────────────────┬─────────┤
│        │  工具上下文栏（随模式变：选择/批注/整理/编辑/表单…）     │         │
│ 左侧   ├───────────────────────────────────────────────────────┤ 右侧    │
│ 导航   │                                                       │ 检视器  │
│ 缩略图 │              文档画布（渲染页 + 批注层）                 │ 批注列表│
│ 大纲   │                                                       │ 字段/层 │
│ 附件   │                                                       │ 查找结果│
│        │                                                       │         │
├────────┴───────────────────────────────────────────────────────┴─────────┤
│  状态栏：页码 · 缩放 · 引擎状态 · 权限锁 · 性能(dev)                      │
└──────────────────────────────────────────────────────────────────────────┘
```

原则：

- **第一屏只有一件事：读文档**。工具按模式出现，不把 Phase 4 的按钮全摆出来。
- 左侧导航、右侧检视器可折叠；默认阅读模式可只留画布 + 精简工具条。
- 不做卡片墙式仪表盘；打开应用 = 打开文件或空白欢迎（最近文件列表即可）。

## 2. 工作模式（Mode）

| 模式 | 快捷键（建议） | 画布行为 | 右栏 |
|------|----------------|----------|------|
| 手型/浏览 | `V` 或按住空格 | 平移、滚轮缩放 | 可关 |
| 文本选择 | `T` | 选字复制、触发批注 | 搜索/选择 |
| 批注 | `A` | 高亮/墨迹/便签 | 批注列表 |
| 整理 | `O` | 缩略图大图重排 | 页面属性 |
| 轻编辑 | `E` | 放文本/图/水印 | 对象属性 |
| 表单 | `F` | 字段焦点 | 字段列表 |
| 签名 | `S` | 放置签名 | 签名库 |
| 红act | `R`（Phase 4） | 框选删除 | 红act 列表 |
| 转换 | 命令面板/菜单 | — | 任务进度 |

模式切换不得丢未保存批注；切换前自动提交当前工具手势。

## 3. 任务流（关键路径）

### 3.1 阅读批注

打开 → 浏览模式翻页 → `T` 选字 → 高亮 → 右侧看列表 → `Cmd/Ctrl+S` 保存。

### 3.2 页面整理

`O` → 多选缩略图 → 拖拽排序 / 右键提取合并 → 另存新文件（默认不覆盖源文件）。

### 3.3 填表签名（Phase 2）

打开 → 表单模式自动探测字段 → Tab 键巡填 → 签名模式盖章 → 保存副本。

### 3.4 扫描件（Phase 3）

打开 → 提示「无文本层」→ 一键 OCR → 变为可搜索 → （可选）可编辑。

## 4. 命令面板

`Ctrl/Cmd+K`：模糊搜所有命令与最近文件。全能阶段功能多，**命令面板是发现性的主出口**，避免工具栏膨胀。

## 5. 视觉与动效（克制、服务性能感）

- 定义 CSS 变量：背景、画布底、强调色、危险色（红act）、成功色。
- **避免**紫渐变模板风、过重玻璃拟态、无意义 glow。
- 动效只做 2–3 个有用的：模式切换工具条 cross-fade、页翻轻微位移、保存成功状态点。
- 文档内容区保持中性灰底，突出纸张，不拿插画当主视觉。

字体：

- UI：选一款清晰的人文无衬线或几何无衬线（非 Inter/Roboto 默认堆），例如 **IBM Plex Sans** 或 **Source Han Sans** 搭配拉丁字体。
- 文档：渲染跟 PDF 字体走，UI 不覆盖正文。

## 6. 快捷键（Phase 1 最小集）

| 键 | 动作 |
|----|------|
| `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` | 打开 / 保存 / 另存 |
| `Ctrl+F` / `F3` | 查找 / 下一处 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做（有编辑后） |
| `Ctrl+Tab` | 下一标签 |
| `+` / `-` / `0` / `1` | 缩放 |
| `删除` | 删除选中批注或页（整理模式） |
| `Esc` | 退回浏览模式 / 关闭弹层 |

## 7. 空状态与错误

- 无法渲染的页：占位 +「重试」+ 错误码（方便自己调试）
- 加密文档：密码框，错误 3 次后仍可再试，不锁死文件
- 保存失败：保留内存副本，提示另存路径

## 8. 欢迎页（非营销站）

仅：

- 应用名（品牌级）
- 打开文件 / 拖拽
- 最近文件
- （可选）性能基准入口（dev）

不要堆功能广告、统计卡片、日程。

## 9. 文案语气

- 短、直接、中性
- 能力边界主动说清（遮盖 ≠ 红act）
- 中文 UI 优先；快捷键提示保留英文键名
