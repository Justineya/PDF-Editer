## 2. Phase 1 功能清单（第一个日用版本）

### 2.1 必须（Must）

- [ ] 打开本地 PDF；最近文件；多标签
- [ ] 连续滚动 + 单页；缩放适配宽度/页面
- [ ] 缩略图轨、书签大纲、页码跳转
- [ ] 文本选择 + 复制（**必须 Text Layer 字形级选字**；当前框选高亮不算完成，见 `07-selection-editing.md` 包 A）
- [ ] 全文搜索（区分大小写/正则可后置）
- [ ] 高亮、下划线、删除线、便签、墨迹（高亮应对齐选字 rects，见 07 包 B）
- [ ] 批注列表面板（按页/按类型过滤）
- [ ] 批注写入 PDF 并另存
- [ ] 合并 PDF、拆分、提取页、删除页、旋转页、拖拽重排
- [ ] 打印
- [ ] 快捷键体系（见 UX 文档）

### 2.2 应该（Should）

- [ ] 自定义图章
- [ ] 批注颜色/线宽预设
- [ ] 导出批注摘要（文本/Markdown）
- [ ] 插入空白页、页面尺寸统一
- [ ] 深色阅读背景（不影响打印色）

### 2.3 可以（Could）

- [ ] 语音备注（本地）
- [ ] 触摸板惯性与手势
- [ ] 命令面板（Ctrl+K）

## 3. Phase 2+ 能力边界声明（产品文案要用）

| 用户可能以为 | 实际（阶段） | 正确表述 |
|--------------|--------------|----------|
| 黑条遮住 = 删掉了 | Phase 2 仅视觉遮盖 | 「遮盖」vs「密文删除(红act)」分两个工具 |
| 能改任何 PDF 文字且完美排版 | Phase 3 起、复杂版式有限 | 「简单版式真编辑；复杂版式框编辑」 |
| OCR 后 = Word | Phase 3 先可检索 | 「可搜索 / 可编辑」分开关 |
| 转 Word 百分百一样 | Phase 3 分档 | 「快速转换 / 保真转换」 |
