# MVP 定义与验收（Phase 0 → Phase 1）

本文定义**第一个可日用版本**的边界。终局全能见 [路线图](./02-roadmap.md)；此处防止范围失控。

## 1. MVP 一句话

> 一个本地桌面 PDF 应用：打开大文件足够快，能流畅阅读与标准批注，能合并拆分提取旋转重排页面，并把批注写回 PDF。

## 2. 包含

- Tauri 桌面壳 + PDFium 渲染
- 多标签、最近文件
- 阅读导航：滚动、缩放、缩略图、大纲、搜索、选字复制
- 批注：高亮、下划线、删除线、便签、墨迹；列表与删除
- 批注保存进 PDF（互操作抽检）
- 页面组织：合并、拆分、提取、删除、旋转、重排
- 打印、另存
- Dev 性能面板 + 200 页基准样例通过预算

## 3. 不包含（故意）

- 云同步、账号、自动更新强制
- 文本真编辑、OCR、Office 转换
- 表单设计器、证书签名、红act
- AI
- 移动端
- 插件市场

## 4. 验收清单

### 性能

- [ ] S-200p：打开到首页可读 ≤ 1.5s
- [ ] 连续快速翻 50 页无明显长时间白屏
- [ ] 墨迹书写主观延迟可接受（≤ 20ms 目标）

### 功能

- [ ] 在 Adobe / macOS Preview / Sumatra 中能看到本应用写入的高亮与便签
- [ ] 合并 5 文件后页序正确、书签策略符合文档说明
- [ ] 提取/删除/旋转后另存，源文件默认不变

### 稳定

- [ ] 连续使用 1 小时（阅读+批注+整理）无崩溃
- [ ] 打开损坏 PDF 有错误提示且不崩

### 自用

- [ ] 作者将系统默认 PDF 关联切到本应用至少 14 天

## 5. 建议实施顺序（工程）

1. SP-1 / SP-2 渲染与缓存 Spike  
2. 壳 + 多标签 + DocumentSession  
3. 阅读导航与搜索  
4. 批注层 + 写回  
5. 页面组织接 pdfcpu/qpdf  
6. 基准与打磨快捷键  
7. 自己用两周 → 再开 Phase 2

## 6. 风险

| 风险 | 缓解 |
|------|------|
| PDFium FFI 工期超预期 | 先静态链官方二进制；Spike 不过则评估商业 SDK（仍本地） |
| 批注互操作差 | 尽早用 Acrobat/Preview 矩阵测试；必要时 XFDF 双写 |
| 页面操作吃内存 | 流式处理、临时目录、大文件走外置 CLI |
| 范围偷偷膨胀到真编辑 | MVP 评审卡「不包含」列表 |
